# 🛒 E-Commerce Sales Analytics Dashboard (Power BI)

## 📌 Project Overview
This project is an interactive Power BI dashboard built to analyze e-commerce sales performance, customer behavior, product profitability, and refunds. It helps businesses monitor key metrics and make data-driven decisions.

---

## 🎯 Objectives

- Analyze overall sales performance
- Compare product-wise revenue and profit
- Track yearly sales trends
- Analyze refunds
- Measure product profitability
- Provide interactive filtering using slicers and tooltips

---

## 🛠 Tools & Technologies

- Power BI
- DAX
- Power Query
- Microsoft Excel

---

## 📊 Dashboard Features

### Executive Dashboard
- Total Revenue
- Total Orders
- Total Sessions
- Total Refund
- Revenue Trend
- Revenue by Product
- Orders by Year
- Refund vs Revenue
- Sessions by Device Type
- Product & Year Slicers

### Product Performance Analysis
- Profit by Product
- Revenue Trend by Year
- Product Share
- Revenue vs Cost
- Profit Margin %
- Interactive Slicers
- Custom Tooltips
